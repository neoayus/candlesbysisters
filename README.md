# Candles By Sisters

React + Vite site. Orders redirect to Instagram and WhatsApp.

    npm install
    npm run dev       # http://localhost:5173
    npm run build     # output in dist/

Edit `src/config.js` (phone, Instagram, email) and `src/data.js` (candles, copy, tiles).
Styles live in `src/index.css`. One component per section in `src/components/`.
